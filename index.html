Invoice Automation

In use at the shop

Turns scanned supplier invoices into stock-upload files for the same shop. Azure AI reads every table cell; the tool matches each line to the shop's items, converts cases into selling pieces by price, and checks every sum. Staff answer a few yes/no questions instead of typing the invoice, and every answer is learned.
