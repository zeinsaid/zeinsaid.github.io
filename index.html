Jawab جواب

Live demo

An AI receptionist for small businesses. It answers customers in their own language (tested in English, Greek and Arabic) from the owner's price list. When it doesn't know, it asks the owner, passes the answer on in the customer's language, and learns it with one tap. Built in a day at the Founding MENA x Replit Hackathon in Dubai. It now answers real customers on my shop's website (below).

Under the hood: Shop Assistant, my engine for a real print shop in Nicosia. Every answer must cite the shop's knowledge base, or it goes to the owner. The model was picked by a 130-case evaluation across Anthropic, OpenAI and Google models: about $0.0003 per message.

  • Python
  • FastAPI
  • SQLAlchemy
  • LLM evaluation
  • Multilingual
  • Multi-provider

Invoice Automation

In use at the shop

Turns scanned supplier invoices into stock-upload files for the same shop. Azure AI reads every table cell; the tool matches each line to the shop's items, converts cases into selling pieces by price, and checks every sum. Staff answer a few yes/no questions instead of typing the invoice, and every answer is learned.

The Plug: my shop's website

Live for customers

The bilingual website of my 24/7 print shop and mini market in Nicosia, and where Jawab works for real: it sits on every page and answers the shop's customers in their own language. Built to look like the shop itself (purple neon sign, yellow walls) rather than a template, it replaced the old WordPress site in November 2026.

Every page in English and Greek, forms that send jobs and files straight to the shop, a map drawn from OpenStreetMap data, and pages that switch instantly. Lighthouse on phones: 95–100 performance on all 22 pages.

  • Astro
  • Tailwind CSS
  • Cloudflare Workers
  • Bilingual (EN/EL)
  • Jawab in production
